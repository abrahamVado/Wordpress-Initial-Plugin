A minimal, production-ready scaffolding for a WordPress plugin with PSR-4 autoloading, a sample CPT, and OAuth-only REST routes.

== Description ==
This is a clean starting point with:
- PSR-4 via Composer
- Admin page stubs (jQuery-only)
- CPT 'demo-plugin'
- WP REST API namespaced under /demo-plugin/v1 with OAuth route stubs

== Installation ==
1. Upload the plugin folder to /wp-content/plugins/.
2. Run `composer install` inside the plugin folder.
3. Activate via Plugins screen.
